Location:     schema_inductor.py, lines 71-108
Size:         38 lines of production code
Status:       ✅ Implemented, ✅ Validated, ✅ Ready

What It Does:
  • Filters non-SQL attributes from LLM-proposed schema
  • Removes type: "array" - not SQL compatible
  • Removes type: "object" - not SQL compatible  
  • Keeps scalars: string, number, boolean, date

Example:
  Before: {"amenities": ["string"], "details": {"phone": "str"}}
  After:  {"parking_available": "boolean", "phone": "string"}

═══════════════════════════════════════════════════════════════════════════
 MCP TOOLS (5-Tool Pipeline)
═══════════════════════════════════════════════════════════════════════════

1. ingest_corpus(documents)
   → Loads documents into DuckDB
   → Creates semantic chunks
   → Stores in documents/chunks tables

2. build_structure(corpus_id)
   → Runs schema induction (4 LLM iterations)
   → Applies Gap 2 filtering
   → Generates SQL CREATE TABLE statements
   → Stores in schema_registry

3. explain_schema(corpus_id)
   → Lists discovered entities
   → Shows attributes and types
   → Displays confidence scores
   → Returns JSON schema

4. query_structured(query_text)
   → Converts natural language to SQL
   → Executes on extracted entities
   → Returns results with provenance
   → Tracks source chunks

5. audit(query_id)
   → Shows which entities were used
   → Lists source documents/chunks
   → Displays extraction confidence
   → Tracks query provenance

 SQL SCHEMA (Generated After Gap 2 Filtering)

CREATE TABLE hotels (
    id UUID PRIMARY KEY,
    name VARCHAR(255),
    rating FLOAT,
    review_count INTEGER,
    established_date DATE,
    price_per_night FLOAT,
    star_rating INTEGER
);

CREATE TABLE hotel_locations (
    hotel_id UUID PRIMARY KEY REFERENCES hotels(id),
    street VARCHAR(255),
    city VARCHAR(255),
    country VARCHAR(255),
    distance_to_airport_km FLOAT,
    distance_to_city_km FLOAT
);

CREATE TABLE hotel_facilities (
    hotel_id UUID PRIMARY KEY REFERENCES hotels(id),
    bar BOOLEAN,
    restaurant BOOLEAN,
    fitness_center BOOLEAN,
    business_center BOOLEAN,
    swimming_pool BOOLEAN,
    room_service BOOLEAN
);

CREATE TABLE hotel_amenities (
    hotel_id UUID PRIMARY KEY REFERENCES hotels(id),
    parking BOOLEAN,
    pet_friendly BOOLEAN,
    free_wifi BOOLEAN,
    breakfast_included BOOLEAN,
    laundry_service BOOLEAN,
    airport_shuttle BOOLEAN
);

 ENTITY EXTRACTION FLOW (4 LLM Iterations)
═══════════════════════════════════════════════════════════════════════════

Step 1: Entity Discovery
  Input:   Raw hotel page text
  Prompt:  "What main entities appear in this document?"
  Output:  Hotel, Location, Facilities, Amenities

Step 2: Attribute Extraction
  Input:   "For Hotel entity, what are the attributes?"
  Output:  name (string), rating (number), review_count (number), ...

Step 3: Type Mapping + Gap 2 Filtering
  Input:   "Convert to SQL types, remove non-SQL types"
  Process: • Identify type: "array" → REMOVE
           • Identify type: "object" → REMOVE
           • Keep scalar types → KEEP
  Output:  SQL-compatible schema only

Step 4: Relationship Discovery
  Input:   "How do entities relate?"
  Output:  Hotel 1-to-1 Location, Hotel 1-to-M Facilities

Step 5: SQL Schema Generation
  → CREATE TABLE statements
  → PRIMARY/FOREIGN KEY definitions
  → Type constraints

Step 6: Entity Extraction
  → Parse documents
  → Extract instances
  → Normalize values
  → Insert into tables

 SAMPLE TEST QUERIES (From 419 Available)
═══════════════════════════════════════════════════════════════════════════

Q1: How many hotel pages are there?
    SELECT COUNT(*) FROM hotels;
    Expected: 422

Q2: Hotels without airport shuttle & business center with parking?
    SELECT COUNT(*) FROM hotels h
    JOIN amenities a ON h.id = a.hotel_id
    JOIN facilities f ON h.id = f.hotel_id
    WHERE a.airport_shuttle = FALSE
    AND f.business_center = FALSE
    AND a.parking = TRUE;

Q3: Hotel with lowest rating that has a bar?
    SELECT h.name, h.rating FROM hotels h
    JOIN facilities f ON h.id = f.hotel_id
    WHERE f.bar = TRUE
    ORDER BY h.rating ASC LIMIT 1;

Q4: Average price for pet-friendly hotels?
    SELECT AVG(h.price_per_night) FROM hotels h
    JOIN amenities a ON h.id = a.hotel_id
    WHERE a.pet_friendly = TRUE;

Q5: Cities with most high-rated hotels (>7.0)?
    SELECT l.city, COUNT(*) as count
    FROM hotels h
    JOIN hotel_locations l ON h.id = l.hotel_id
    WHERE h.rating > 7.0
    GROUP BY l.city
    ORDER BY count DESC;
